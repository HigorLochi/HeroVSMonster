# Hero VS Monster Mini Game

This project is a Python console application designed to create a battle of a hero againt a monster.

## Technologies
Python 3

## Requirements
Python 3 installed

## Execution
1. Enter the project folder
2. Execute: py -m app.main

## Instructions
### Objective
Defeat the opponent

### Overall stats
1. Player life = 100
2. Player damage = 1 - 10
3. Player critical rate = 20%
4. Monster life = 150
5. Monster damage = 5 - 15
6. Monster critical rate = 20%

### Player options
1. Attack( will attack the opponent dealing or not crit damage)
2. Defend( opponent will deal only 50% of his base attack)
3. Evade( the opponent's attack will be 50% evadable)

### Monster options
1. Attack( will attack the player dealing or not crit damage)
2. Stop ( the monster will do nothing)

## Notes
1. Console-based application
