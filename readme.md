# Hero VS Monster Mini Game

This project is a Python console application designed to create a battle of a hero againt a monster.

## Technologies
Python 3

## Requirements
Python 3 installed

## Execution
1. Enter the project folder
2. Execute: py -m app.main

## Instructions
### Objective
Defeat the opponent

### Overall stats
1. Player life = 100
2. Player damage = 1 - 10
3. Player critical rate = 40%
4. Player Defence Percentage = 70%
5. Player Evasion Chance = 80%
6. Monster life = 150
7. Monster damage = 5 - 15
8. Monster critical rate = 20%
9. Monster Defence Percentage = 100%
10. Monster Evasion Chance = 40%

### Options
1. Attack
2. Defend
3. Evade

## Notes
1. Console-based application
